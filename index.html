What this version can and cannot do

  • Extract selectable text from a PDF and create editable four-option MCQ drafts using text patterns and fill-in-the-blank generation.
  • Keep English/Gujarati translation fields for review; this offline version does not automatically translate every question into Gujarati or understand every scientific concept.
  • Includes a test timer up to 180 minutes, NEET scoring (+4 correct, −1 incorrect, 0 unanswered), question navigation, and answer analysis.
  • For scanned PDFs, automatic OCR, or high-quality AI-generated bilingual questions, an OCR/AI service would need to be added separately.
